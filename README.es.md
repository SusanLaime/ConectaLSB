# ConectaLSB 🤟

**ConectaLSB** es una plataforma de Inteligencia Artificial diseñada para reconocer e interpretar la **Lengua de Señas Boliviana (LSB)** utilizando técnicas de visión por computadora y aprendizaje automático. El proyecto emplea **MediaPipe** para detectar puntos de referencia de las manos y procesar gestos de lenguaje de señas en tiempo real.

## 📖 Descripción General

Las barreras de comunicación pueden afectar significativamente la accesibilidad y la inclusión de las comunidades sordas y con discapacidad auditiva. ConectaLSB busca abordar este desafío mediante una solución tecnológica capaz de detectar e interpretar gestos de la Lengua de Señas Boliviana utilizando Inteligencia Artificial.

Combinando técnicas de visión por computadora con modelos de aprendizaje automático, la plataforma captura movimientos de las manos, extrae características relevantes y clasifica gestos de lenguaje de señas para facilitar la comunicación y promover la accesibilidad.

## ✨ Características

* Detección y seguimiento de manos en tiempo real.
* Reconocimiento de gestos de lenguaje de señas.
* Clasificación de gestos basada en Inteligencia Artificial.
* Visión por computadora impulsada por MediaPipe.
* Flujo de trabajo para creación y entrenamiento de conjuntos de datos.
* Aplicación accesible y educativa.

## 🛠️ Tecnologías Utilizadas

* Python
* MediaPipe
* OpenCV
* Aprendizaje Automático (Machine Learning)
* Visión por Computadora

## 🎯 Objetivo del Proyecto

El objetivo principal de ConectaLSB es contribuir a la inclusión digital y la accesibilidad mediante el desarrollo de soluciones tecnológicas que faciliten la comunicación a través del reconocimiento de la Lengua de Señas Boliviana.

## 🚀 Mejoras Futuras

* Ampliar el vocabulario de señas soportadas.
* Mejorar la precisión del reconocimiento.
* Incorporar reconocimiento continuo de señas.
* Desarrollar una versión móvil de la plataforma.
* Integrar funcionalidades de generación de texto y voz.
