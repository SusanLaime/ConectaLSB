# ConectaLSB 🤟

**ConectaLSB** is an Artificial Intelligence platform designed to recognize and interpret **Bolivian Sign Language (LSB)** using computer vision and machine learning techniques. The project leverages **MediaPipe** to detect hand landmarks and process sign language gestures in real time.

## 📖 Overview

Communication barriers can significantly impact accessibility and inclusion for deaf and hard-of-hearing communities. ConectaLSB seeks to address this challenge by providing a technological solution capable of detecting and interpreting Bolivian Sign Language gestures through Artificial Intelligence.

By combining computer vision techniques with machine learning models, the platform captures hand movements, extracts relevant features, and classifies sign language gestures to facilitate communication and accessibility.

## ✨ Features

* Real-time hand detection and tracking.
* Sign language gesture recognition.
* AI-based gesture classification.
* Computer vision powered by MediaPipe.
* Dataset creation and training workflow.
* Accessible and educational application.
